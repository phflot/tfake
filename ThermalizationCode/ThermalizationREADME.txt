## Thermalization Code for T-FAKE  

This directory contains code related to the thermalization process in the T-FAKE paper.  

### Files and Dependencies  
- **Main script:** `thermalization.py` (Tested with Python 3.10.13)  
- **Jupyter Notebook:** Visualizes training progress, including:  
  - Batch-wise training loss  
  - Sample "thermal" T-FAKE images  

Due to privacy restrictions communicated by the SEJONG dataset authors, we are unable to share SEJONG images.  

### Datasets  
- **SEJONG Dataset:** Not publicly available. To access it, please contact the authors directly. More information: [SEJONG Face Database](https://github.com/usmancheema89/SejongFaceDatabase)  
- **FAKE Dataset:** Freely available at [Microsoft Face Synthetics](https://github.com/microsoft/FaceSynthetics)  

The dataset classes are provided, and the code should run as long as the datasets are correctly formatted and their paths are specified.
